开源项目

  1. OpenMontage：首个开源自主视频制作系统

    提供12条制作流水线、100余种工具和700+代理技能文件，将 AI 编码助手转化为完整的视频制作工作室。

  2. text-to-cad：为 AI 代理赋予 CAD 超能力

    通过自然语言指令让代理直接生成和编辑 CAD 模型，实现文本到 CAD 的即时转换。

  3. FalkorDB：基于 GraphBLAS 的超速图数据库

    使用稀疏邻接矩阵的 GraphBLAS 实现高速图存储，专为 LLM 的 GraphRAG 知识图谱提供最优支持。

  4. OptMem：AI 代理的永久记忆模块

    提供 426-token 的提示脚本，实现即插即用的长期记忆功能，让代理能够持续记住关键信息。

  5. gstack：Gar​ry Tan 的 Claude Code 全套工具集

    集合 23 个面向 CEO、设计师、工程经理等角色的工具，实现从代码到发布的全流程 AI 助手。

  6. heretic：自动化语言模型审查过滤移除

    通过全自动化手段去除模型输出中的审查限制，让模型恢复完整生成能力。

  7. free-claude-code：免费使用 Claude Code 等多模型的终端/IDE 集成

    在终端、IDE、浏览器等环境中免费调用 Claude Code、Codex、OpenCode 等，提供 1.3B+ 免费 token，支持语音及多模型切换。

  8. radar：开源 Kubernetes UI 与 AI 代理服务器

    提供可视化的集群监控界面，内置 MCP 服务器供 AI 代理使用，集成问题诊断、拓扑、事件时间线等功能于单一 Go 二进制。

  9. awesome-ai-agents：300+ 高质量代理 AI 资源合集

    收录超过 300 项代理 AI 相关项目、工具与文献，帮助开发者快速定位所需资源。

  10. NandhaKishorM/laya：非自回归系统1决策引擎

    非自回归决策引擎，在单次前向传播中对任意文本实现类型化选择、打分和是/否判断，支持100多种语言，并通过路由器为每个请求挑选合适的检查点。

热门模型

  1. Cloudflare/clef 多模态模型

    在 Hugging Face 上的 image‑text‑to‑text 模型，支持根据图片和文字输入生成文本，热度 95.6，首次登榜并排名第一，获 1548 赞。

  2. convaiinnovations/laya 文本分类模型

    Hugging Face 上的 text‑classification 模型，提供高效文本分类，热度 94.6，排名第二，获 5256 赞，并在代码库中关联 NandhaKishorM/laya。

  3. abenzerps/Qwen‑Image‑2.1‑Uncensored‑GGUF 文本到图像模型

    在 Hugging Face 的 text‑to‑image 模型，使用 GGUF 格式提供未审查的图像生成能力，热度 93.7，排名第三，获 3310 赞。

  4. Lightricks/LTX‑2.5 图像到视频模型

    Hugging Face 上的 image‑to‑video 模型，可将单张图片扩展为短视频，热度 93.2，排名第四，获 6539 赞。

  5. Qwen/Qwen3.8‑27B 多模态大模型

    在 Hugging Face 的 image‑text‑to‑text 大模型，参数 27B，热度 91，排名第五，获 17056 赞，首次登榜。

  6. autotrust/JEV‑27B‑VL 多模态模型

    Hugging Face 上的 image‑text‑to‑text 模型，27B 参数，热度 88.5，排名第六，获 811 赞。

  7. Aleph‑Alpha/Kolibri‑1 文本生成模型

    在 Hugging Face 的 text‑generation 模型，热度 87.5，排名第七，获 655 赞。

  8. Cloudflare/clef‑flash 快速多模态模型

    Hugging Face 上的 image‑text‑to‑text 轻量版模型，热度 85.7，排名第八，获 548 赞。

  9. autotrust/GEV‑26B‑Decide 文本分类模型

    Hugging Face 上的 text‑classification 模型，26B 参数，热度 83.3，排名第九，获 489 赞。

  10. Venastine-Research/Xing4.0-29B-A4B-GGUF

    Venastine-Research 推出的 Xing4.0-29B-A4B-GGUF 是一款 290 亿参数的文本生成模型，采用 GGUF 格式，针对大规模语言建模优化，已在 Hugging Face 热度榜第10位，获 421 点赞。
