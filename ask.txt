### 二、手把手配置步骤（只需 3 步）
  #### 第 1 步：在 GitHub 仓库开启 GitHub Pages
  1. 打开您的 GitHub 仓库页面，点击顶部 Settings。
  2. 左侧菜单找到 Pages。
  3. 在 Build and deployment 下方的 Source 下拉菜单中，选择：
  👉 GitHub Actions（注意：不是从分支 Deploy from a branch）。
  4. 页面会自动保存。
  #### 第 2 步：配置 GitHub Actions 写入权限

  因为 Actions 需要向 data 分支自动提交抓取快照并发布 Pages：
  1. 依然在仓库 Settings 页面，左侧点击 Actions → General。
  2. 页面滚动到最底部找到 Workflow permissions。
  3. 勾选 Read and write permissions（读写权限）。
  4. 点击 Save 保存。
  #### 第 3 步：配置 LLM 密钥（用于 AI 润色翻译）

  1. 在仓库 Settings 页面，左侧选择 Secrets and variables → Actions。
  2. 在 Repository secrets 区域点击 New repository secret，添加以下参数：
      • RESONANCE_LLM_API_KEY：您的 LLM API Key（如 OpenAI、DeepSeek、OpenRouter、OneAPI 等密钥）。
      • RESONANCE_LLM_BASE_URL：LLM API Base URL（例如 https://api.deepseek.com/v1 或 https://openrouter.ai/api/v1）。
      • RESONANCE_LLM_MODEL：模型名称（例如 deepseek-chat 或 gpt-4o-mini）。

  ### 三、如何立即测试运行？

  把代码 git push 推送到 GitHub 之后：

  1. 打开仓库的 Actions 标签页。
  2. 左侧点击 Daily 工作流。
  3. 右侧点击 Run workflow 按钮，选择 main 分支点击绿色 Run workflow。
  4. 观察流水线运行：
      • 绿色勾选完成之后，进入 Settings → Pages 就能看到您站点的访问链接（通常是 https://<用户名>.github.
      io/<仓库名>/）。
      • 以后该工作流会自动按 Schedule 定时运行，无需人工干预。
